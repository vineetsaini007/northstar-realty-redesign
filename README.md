# Northstar Realty

A fictional real estate website redesign case study and interactive property discovery demo. Built with React, TypeScript, and Vite.

## Structure

- `src/data/` — typed listing and agent data
- `src/components/` — search, listing, detail, enquiry, team, and redesign story
- `src/styles/` — global tokens and feature styles

## Features

Search by area, property type, bedroom count, and maximum price. Open listing details, save favorites, meet agents, and submit a simulated enquiry. The redesign section explains the experience before and after.

All properties, prices, addresses, agents, claims, and enquiries are fictional portfolio content. No form data is sent or stored.

```bash
npm install
npm run dev
npm run build
```
